# 验收清单

## 账号与权限

- [ ] 游客可打开首页、搜索、排行、标签和公开模型详情，不能发布/点赞/收藏/关注/私信。
- [ ] 新用户可注册并登录；错误密码、重复邮箱、弱密码、敏感昵称有明确提示。
- [ ] 作者只能编辑/下架自己的模型；普通用户访问后台会回首页。
- [ ] 审核员可审核和处理举报，但不能修改系统设置或备份恢复。
- [ ] 仅超管可调整角色、修改设置、创建/恢复备份、清理缓存。
- [ ] 封禁用户无法登录；禁言用户无法发布、评论、私信。关键操作出现在审计日志。

## 发现与互动

- [ ] 首页展示推荐、最新、热门、标签、作者和公告；无数据时页面仍可用。
- [ ] 搜索覆盖标题、描述、标签、作者；分类/标签/时间/排序和分页有效。
- [ ] 登录用户产生搜索历史；历史可清理；热门搜索有结果。
- [ ] 排行可切换日/周/月/总榜和热度/浏览/点赞/收藏，显示作者贡献榜。
- [ ] 模型详情产生浏览与历史，点赞/收藏再次点击可取消且计数一致。
- [ ] 可关注作者、订阅作者/标签、发表评论、复制分享链接。
- [ ] 相关推荐不包含当前模型，未发布内容不会出现在公开列表。

## 发布与审核

- [ ] 缺少标题、描述不足、无文件/外链、非法 URL、标签重复或敏感词会被拒绝。
- [ ] 上传非法图片 MIME、超限文件、非法扩展名会失败；失败后可重新选择。
- [ ] 新模型提交后为 PENDING，公开搜索不可见，作者可在“我的发布”预览。
- [ ] 审核员通过后为 APPROVED，公开可见，并通知作者及订阅者。
- [ ] 驳回必须填写原因，作者可看到原因；编辑后重新进入 PENDING。
- [ ] 举报必须选择原因；后台可驳回、标记处理或处置对象，举报者收到通知。
- [ ] 申诉状态 APPEALING 会重新进入处理队列。

## 私信与通知

- [ ] 作者主页可发起私信，两个会话参与者可轮询收到消息。
- [ ] 未读提醒和全部已读有效；敏感词、禁言和频率限制有效。
- [ ] 被拉黑方无法继续发送；私信骚扰可举报并进入后台。

## 后台与运维

- [ ] 模型可推荐、置顶、下架/恢复，勾选多个模型可批量操作。
- [ ] 用户可认证、禁言/封禁；超管可改角色。
- [ ] 标签可启停/删除；分类、评论、合集可管理；敏感词可新增/启停/删除。
- [ ] 系统设置可保存；统计卡、热门模型、CSV 导出和健康检查可用。
- [ ] 安装 PostgreSQL 客户端后可创建备份并生成 SUCCESS 记录。
- [ ] 仅在隔离测试库验证恢复，确认 `RESTORE` 二次确认与审计记录。

## 响应式 / PWA / SEO / 无障碍

- [ ] 360px、768px、1280px 宽度无横向溢出，移动菜单、发布、详情和后台核心操作可用。
- [ ] 键盘可访问导航、表单、对话框；焦点清晰，图片有替代文本，表单有标签。
- [ ] 生产构建后生成 Service Worker，可安装；离线可打开缓存页面并显示离线提示。
- [ ] 模型详情有 canonical、OG、Twitter Card 和 JSON-LD；个人/后台不索引。
- [ ] Sitemap 和 robots 可访问；分享卡片使用模型封面。
